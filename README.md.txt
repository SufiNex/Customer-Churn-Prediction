# Customer Churn Prediction

## Project Overview
This Machine Learning project predicts whether a telecom customer is likely to leave the service.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

## Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest

## Features
- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- Data Preprocessing
- Model Training
- Hyperparameter Tuning
- Model Evaluation
- Streamlit Deployment

## Run Locally

Install dependencies:

pip install -r requirements.txt

Run application:

streamlit run app.py
